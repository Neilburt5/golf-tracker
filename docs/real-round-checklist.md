# Real-round test checklist (V0.1)

## The day before
- [ ] Open the app on the iPhone with Wi-Fi on; confirm the "Build:" time is the latest deploy.
- [ ] If the "Nueva versión disponible" banner shows, tap "Actualizar" and re-check the build time.
- [ ] Airplane mode: open the app, start a test round, save one hole, delete the test round.
- [ ] Rounds → "Guardar copia" and keep the .json somewhere safe (iCloud Files).
- [ ] Battery above 80%; Low Power Mode and auto-lock behaviour known (screen may lock between shots).

## Before teeing off
- [ ] Airplane mode ON (simulates the course; also saves battery).
- [ ] New round: course, tees, hole range correct.
- [ ] Screen brightness up.

## During the round (note answers in your phone's Notes)
- [ ] Time to record each hole, on 3 holes: target 10-15 s. Which hole took longest, and why?
- [ ] Can every control be reached with one hand (thumb)? Any mis-taps?
- [ ] Is text readable in direct sun: hole number, par, score, "Guardado ✓", grey text?
- [ ] After the screen locks and you unlock it, is the hole data still there?
- [ ] Switch to another app and come back: still on the same hole?
- [ ] Go back one hole and forward again: data intact?
- [ ] Did GIR auto-suggestion match reality? How often did you correct it?
- [ ] Anything you wanted to record but could not? (Write it down; do not build it yet.)

## After the round
- [ ] Review the summary: totals match your scorecard?
- [ ] Finish round.
- [ ] Export to Excel via share sheet; open the file on a computer: sheets, totals, empty cells.
- [ ] Save a JSON backup.
- [ ] Write down the top 3 annoyances for V0.1.x fixes.
